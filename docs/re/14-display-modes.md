# 顯示模式

位址除標明 `dseg:` 者外，都是 IDA 線性位址（映像基底 `10000h`）。`dseg:X` 的線性位址是 `1CBC0h + X`。下文的 M 指 `byte_1CF74`（`dseg:3B4h`），P 指 `byte_1CF75`（`dseg:3B5h`）。E、C、H 是 M 的三個值：`'E'`（VGA 與 EGA）、`'C'`（CGA）、`'H'`（MGA，Hercules）。

## 1. 摘要

| 項目 | 結論 | 等級 |
|---|---|---|
| 模式怎麼選 | `start` 呼叫 `sub_10297`（`10028h`）顯示文字選單，V、E、C、H 鍵各寫一次 M 與 P。沒有顯示卡偵測呼叫（只有 `int 11h` 讀設備字），未發現命令列或環境變數的讀取，執行中沒有切換入口。`sub_10297`、`sub_10095` 都只有這一個呼叫端 | 靜態已證實 |
| 判斷點數量 | M 與 P 的指令參照共 131 處：讀 M 105 處、讀 P 21 處、寫 5 處。可達 116 處，不可達 15 處 | 靜態已證實 |
| 判斷點的位置 | `14458h` 到 `17DF8h`（玩家、實體、子彈、碰撞、特效、亂數）和四個關卡主迴圈、八個幀函式本體沒有任何判斷點 | 靜態已證實 |
| 模式是否影響模擬 | 程式路徑不受影響。模擬資料有一項受影響：第三關的地圖陣列。E 讀 `SHT.SCN`，C、H 讀 `SHT.SCR`，兩者在 12,000 格中有 514 格的零與非零不同，而這份陣列就是地形碰撞格 G4 的內容。其餘模擬欄位在展示錄影逐筆相同。四關重跑中，第一、二、四關只有驅動程式一幀輸入偏移造成的玩家彈池差異 | 靜態已證實；動態已證實 |
| 模式專屬、但不屬於模擬的狀態 | M、P、視訊段 `word_2686C`、頁偏移 `word_26872`、列位址表 `dseg:A00Ah`、圖庫段變數、背景暫存區的位置。資料段 64 KB 中，展示錄影四個時間點的差異只落在這些位址與計時器、按鍵狀態 | 動態已證實 |
| 音效 | E 的特效 blit 同時驅動 PC 喇叭（爆炸、命中聲），C、H 沒有這個動作 | 靜態已證實 |
| 圖庫 | 單色版 21 個圖庫檔加 `SHT.SCR`。項數與彩色版相同，只有 `MAP` 少 12 塊（1,007 對 1,019）。單色項目 1,325 項，寬度是彩色版 2 倍的有 1,251 項（含 `MAP` 1,007 塊），其餘 74 項不是 2 倍。高度與彩色版不同的有 122 項 | 靜態已證實 |
| 重製 | 需要一條 640×200、1 bit 的繪製路徑（C、H 共用），Hercules 另有 1.5 倍垂直呈現。邏輯只有第三關地形要決定資料來源。切換模式時，核心的模擬欄位不用動，繪製層和第三關 G4 要重建 | 見第 8 節 |

## 4. 判斷點明細

欄位說明：

- 比較：M 或 P 與立即值的比較，或對它們的寫入。
- 各模式走向：E、C、H 各自的去向。段落數單位是 16 位元組。`xN` 表示重複 N 次。
- 調色盤列：Y 分支（EGA）執行 INT 10h AX=1002h，ES:DX 指向 17 位元組屬性表。N 分支（VGA）兩次呼叫 INT 10h AH=10h AL=12h，BX 先 0 再 30h，CX=16，ES:DX 指向 48 位元組 DAC 表。C、H 在每個調色盤函式的第一個比較就 `retn`。
- 函式：以可達的 call 目標為函式起點，與 IDA 的 proc 邊界不同。IDA 把 `retn` 之後的死碼算進前一個函式，這類列寫「無起點」。
- 等級：分支結構由反組譯與位元組讀得，記為靜態已證實。標有「動態已證實」的列，在 dosgolem 的 C、H 重跑中量到相符的結果（見第 5.2 節與第 6 節）。

### 5.1 靜態結果

- 131 處參照的位址見第 4 節。位址 `14458h`（`sub_14458`，玩家輸入）到 `17DF8h`（`sub_17DF9` 之前）涵蓋玩家、實體、子彈、碰撞、特效與生成，沒有任何一處。第一到第四關的主迴圈（`sub_10CD0`、`sub_13205`、`sub_13A51`、`sub_13DAF`）和八個幀函式（`sub_10F41`、`sub_10F9F`、`sub_132EB`、`sub_13344`、`sub_13B0A`、`sub_13B75`、`sub_13EAB`、`sub_13EF9`）本體也沒有。

### 5.4 音效

`sub_18DCC`（`18DCCh`，位元組 `80 3E B4 03 45 75 3C`）是特效腳本圖的 blit。E 時對 `MY.GO` 的 4 個平面各呼叫一次 `sub_192EA`：每列 OR 寫入，同時以來源資料寫 PIT 通道 2 的除數並開關喇叭閘門（`sub_187A6`、`sub_187B3`、`sub_187BB`）。C、H 走 `sub_1979F`，只有 OR 寫入。爆炸與命中的喇叭聲因此只在 E 存在，細節見 [13-audio-and-misc.md](13-audio-and-misc.md) 4.3。喇叭另有由 `byte_2684F` 驅動的派發（`sub_18672`），與模式無關。AdLib 音樂（`A.MIX`、`B.MIX`）三個模式用同樣的檔案與同樣的呼叫。

### 5.5 切換模式時模擬是否不變

- 核心欄位（玩家、實體、子彈、特效、G1、G2、亂數索引、幀計數、`bg`）與模式無關。不用因為切換而改值或重算。
- 第三關的 G4 與捲動中的地圖由地圖陣列決定。切換時若換地圖陣列，同一個捲動位置的地形格會改變，模擬在該幀之後與不切換時不同。若固定使用 `SHT.SCN` 當地形，單色畫面用 `SHT.SCR` 與 `MAP.BDB` 繪製，畫面與碰撞在 514 格不一致。取捨由使用者決定，見第 8 節。
- 繪製層的狀態是模式專屬的：顯示頁內容、背景暫存區（E 在顯示記憶體內，單色在主記憶體）、載入的圖庫與遮罩、頁偏移、調色盤。原版沒有切換程序，沒有對拍來源。重製要依當下的 `bg`、關卡狀態與頁奇偶重建。

## 7. 繪製路徑

### 7.1 三個模式的對照

| 項目 | E（VGA、EGA） | C（CGA） | H（MGA，Hercules） |
|---|---|---|---|
| 設定函式 | `sub_100C5` | `sub_100AF` | `sub_100D6`、`sub_1010B` |
| 視訊模式 | INT 10h AX=0Dh，320×200，16 色，4 平面 | INT 10h AX=6，640×200，1 bit | 不呼叫 BIOS。寫 3BFh=03h、3B8h，再依 `dseg:3B6h` 寫 CRTC 12 個暫存器 |
| 顯示記憶體 | A000h | B800h | B000h |
| 每列位元組 | 40 | 80 | 80 |
| 列位址表（`dseg:A00Ah`） | `n × 28h` | 偶數列 `n/2 × 50h`，奇數列加 `2000h`（`dseg:9E7Ah`） | 偶數列 `n/2 × 50h`，奇數列加 `4000h`（`dseg:9CEAh`） |
| 頁 0、頁 1 | A000:0000、A000:8000 | B800:0000、B800:4000 | B000:0000、B000:8000 |
| `word_26872`（畫頁偏移） | `8000h`／0 | `4000h`／0 | `8000h`／0 |
| 翻頁 | CRTC 3D4h 索引 0Ch 寫 0 或 80h（`sub_19A37`、`sub_19A88`） | INT 10h AH=5，AL=0 或 1 | 3B8h 寫 0Ah（頁 0）或 8Ah（頁 1） |
| 背景暫存區 | 顯示記憶體內：A 為 `1F40h`～`7FFFh`，B 為 `9F40h`～`FFFFh`，列距 80 位元組（表 `dseg:A19Ah`） | 主記憶體 `word_1CF70`、`1CF72` 段，列距 160 位元組（表 `dseg:A4BAh`），每塊 0D00h 段落 | 同 C |
| blit | 4 平面各呼叫一次，用 GC 3CEh 的寫入模式與資料旋轉，SEQ 3C4h 的平面遮罩 | 單次字組版（OR、AND、覆寫、取反） | 同 C |
| 遮罩 | 先 AND（GC `0803h`）再 OR 4 平面 | 先 AND 字組再 OR 圖 | 同 C |
| x 單位 | 位元組（8 像素） | 乘 2（16 像素，字組對齊） | 同 C |
| y 範圍 | blit 到列 189（`0BDh`） | blit 到列 190（`0BEh`） | 同 C |
| 填色 | GC 寫入模式 2 | 字組填，`dx`=1（`sub_1A287`）或 `0Bh`（`sub_1929F`）改成 `0AAAAh` 點陣 | 同 C |
| 清除頁 | `sub_1A317`：從 `word_26872` 起 `0ED8h` 字組（190 列） | `sub_1A332`：B800:[page] 2000h 字組 | `sub_1A332`：B000:[page] 3FFFh 字組 |
| 整頁清除 | `sub_188B1`：A000:0 與 8000h 各 `0FA0h` 字組 | `sub_188DE`：B800:0 的 3FFFh 字組 | `sub_188CD`：B000:0 的 7FFFh 字組 |
| 調色盤 | 20 組，EGA 用屬性暫存器，VGA 用 DAC | 無（遊戲不設定，前景由 BIOS 預設） | 無 |
| 專屬操作 | 特效 blit 驅動喇叭 | 無 | `sub_1117F`：每幀把頁內 `0000h`～`1FFFh` 複製到 `2000h`～`3FFFh` |

Hercules 的幾何屬於強推論，依據是 CRTC 暫存器值 `35 28 2E 07 6A 01 64 64 02 02 00 00`（`dseg:3B6h`）和 `sub_1117F`：

- R1=28h，每字元 16 像素，水平 640 像素；列位址表每列 80 位元組。
- R6=64h（100 字元列）、R9=02h（每字元列 3 條掃描線），共 300 條可見掃描線。
- Hercules 圖形模式的掃描線序號決定位址的第 13、14 位元，所以每個字元列的 3 條掃描線取 `0000h`、`2000h`、`4000h` 三個群。遊戲只畫偶數列（`0000h` 群）和奇數列（`4000h` 群），`sub_1117F` 把偶數列群複製到 `2000h` 群，中間那條掃描線重複偶數列。200 個遊戲列於是顯示成 300 條掃描線，垂直 1.5 倍。
- 標準 Hercules 圖形模式的暫存器是 `35 2D 2E 07 5B 02 57 57 02 03 00 00`（720×348），與本遊戲的值不同。

CGA 的第二頁位於 B800:4000，由 `12932h` 的清除範圍（`BC00h` 段）與 `19A76h` 的 `4000h` 證實。真實 CGA 卡只有 16 KB 顯示記憶體，INT 10h AH=5 在模式 6 是否有翻頁效果，這份分析沒有驗證。

### 7.3 頁面與幀順序

兩頁交替的順序在各關主迴圈相同：`sub_19A37`（顯示頁 0、畫頁 1）→ 一個幀 → `sub_19A88`（顯示頁 1、畫頁 0）→ 一個幀。每幀等 2 個 tick（`sub_11097` 等 `ds:0A7F9h` 達到 `cx`，該計數由 INT 8 處理常式增加），與模式無關。全檔沒有 `3DAh`、`3BAh` 埠位址常數，沒有等垂直回掃的呼叫。H 的 `sub_1117F` 在幀函式末端、翻頁之前複製掃描列群（[11-entities-combat.md](11-entities-combat.md) 1.1 的步驟 16）。

### 7.4 調色盤與文字模式

- E：20 組調色盤（表見 [02-file-formats.md](02-file-formats.md) 調色盤一節），EGA（P=`'Y'`）寫屬性暫存器，VGA（P=`'N'`）寫 DAC。`start` 的 `10052h` 呼叫 `sub_1007D`，在選模式之後對所有模式無條件執行一次 INT 10h AX=1002h（屬性表在 `dseg:3C2h`）。在 C、H 的卡上這個呼叫的效果沒有驗證。
- C、H：沒有調色盤，圖庫是 1 bit，位元 1 為亮、0 為暗。CGA 的前景色是否為白由 BIOS 預設決定，遊戲不設。
- 文字模式：`start` 以 INT 10h AX=3（保留螢幕，AL 或 80h）進文字模式，`sub_10297` 用 INT 10h AH=9、2、7 畫方框與選單，字串在 `dseg:186h`：`ESC.) QUIT TO DOS.`、`V .) FOR VGA.`、`E .) FOR EGA.`、`C .) FOR CGA.`、`H .) FOR MGA.`。離開遊戲時 `sub_10058` 以 INT 10h AX=3 還原。選單之後 `sub_10095` 才切到圖形模式，之後在遊戲中不再進出文字模式。
