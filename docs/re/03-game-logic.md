S.EXE 內層是手寫組語（強推論），沒有 C runtime，全域變數直接定址，呼叫慣例是暫存器加全域變數。

## 主流程

```text
start
  ├ sub_10297    文字選單：偵測 AdLib、選顯示模式、Esc 離開
  ├ sub_10135    配置記憶體
  ├ sub_1AA38    載入 A.MIX
  ├ sub_10671    密碼畫面（見 01-boot-chain.md）
  ├ sub_10095    切換顯示模式
  └ sub_10B44
       ├ sub_10C86  載入 MY 圖庫與共用介面
       └ sub_10CD0  第一次進入時，sub_10FEA 看到 byte_1CFAC='N'，轉入標題循環
            └ sub_11556  標題循環，返回後程式結束
                 ├ 開場動畫
                 ├ 開場期間按任意鍵 → 正式遊戲
                 ├ 開場跑完無按鍵 → sub_11685 展示模式，輪播第一、二關，按鍵回開場
                 ├ 標題按 C → sub_12588 選單，Enter 回標題循環，再按鍵才開始
                 └ 正式遊戲
                      sub_11C6B 過場 J1 → sub_10CD0 第一關
                      sub_11E46 過場 J2 → sub_13205 第二關
                      sub_121DD 過場 J3 → sub_13A51 第三關
                      sub_12379 過場 J4 → sub_13DAF 第四關
                      sub_141D0 片尾，單按 Q 結束
```

`sub_10CD0` 同時是第一關與進入標題循環的路徑。`sub_11556` 一開始把 `byte_1CFAC` 改成 `'Y'`，之後再進來才是真正的第一關。

各關回傳 `dx`：`Q` 離開到 DOS（exit code 76），`E` 回標題，`C` 進下一關。

| 函式 | 關卡代號 `byte_1CFDB` | 圖庫 | 背景／地圖 | 展示錄影 |
|---|---|---|---|---|
| `sub_10CD0` | `A` | `SHT1` | `BH1` | `DM1` |
| `sub_13205` | `B` | `SHT2` | `BH2` | `DM2` |
| `sub_13A51` | `C` | `SHT3` | `MAP` + `SHT.SCN` | 無 |
| `sub_13DAF` | `D` | `SHT4` | `BH4` | 無 |

## 時間基準

- 遊戲 tick 是 18.2065 Hz，每畫一個頁面等 2 個 tick，所以邏輯更新是 9.10 次／秒。有無 AdLib 都一樣。
- `ASMDRV` 會把 PIT 改成 400.128 Hz（`A.MIX`）或 480.154 Hz（`B.MIX`），但它的 INT 8 用累加器只把 18.2 Hz 轉發給遊戲。
- 每個邏輯幀畫一頁，兩頁交替（`A000:0000`、`A000:8000`）。幀計數 `word_1CFE2` 是關卡內的時間基準，所有時間表與階段門檻都用它。
- `sub_1100A` 無條件把幀計數畫在畫面底部，發行版看得到這串數字。

## 規則摘要

- 橫向捲軸。沒有分數、生命數、接關或 Game Over 畫面。雙方活躍位元都清零就回開場。
- 血量 `FFh`，每次命中右移一位，8 次歸零，命中後無敵 6 幀，第一關與展示模式才重設，血量與武器跨關保留。
- 死亡後倒數 15 幀，只清該玩家的活躍位元。雙人時另一人繼續，不復活。
- 撿取順序：第 1 次砲座 1，第 2 次砲座 2，第 3 次起換武器 `L`、`B`、`K`、`S`。一次按放射一發，第二砲座存在時按住可充能，放開射出大掃射。
- 頭目由合成圖、隱藏碰撞體、可見分件組成。核心（代碼 `E`）死亡即過關。第四關過關條件是幀 > 1062 且 15 個實體槽全空。
- 亂數是 75 項固定表（`dseg:42Ch`），每個實體用自己的索引，只用於敵人開火，沒有全域種子。

## 輸入

INT 9 處理常式 `1A83Dh` 把按鍵狀態寫到 `線性 2748Bh + 掃描碼`：1 按下，2 放開。遊戲本體不用 `int 16h`。

| 動作 | 第一玩家 | 第二玩家 |
|---|---|---|
| 上 | ↑（48h） | `T`（14h） |
| 下 | ↓（50h） | `B`（30h） |
| 左 | ←（4Bh） | `F`（21h） |
| 右 | →（4Dh） | `H`（23h） |
| 斜向 | Home、PgUp、End、PgDn | 細節見 `11` |
| 開火 | 右 Shift（36h） | 左 Shift（2Ah） |
| 切換砲座朝向 | `/`（35h） | `Z`（2Ch） |

`RS2.JOY` 的內容與此相符，JOYMOUSE 把搖桿映射成鍵盤掃描碼。

## 熱鍵（皆已實跑）

| 按鍵 | 行為 |
|---|---|
| Esc | 暫停，再按一次恢復（`sub_10ECB`）。第一關每輪檢查一次，第二到四關每頁檢查一次，位置見 [12](12-stages-presentation.md) 第 4.1 節 |
| `S` | 切換 `byte_2684E`，同時靜音音樂與喇叭 |
| Ctrl+Q | 離開到 DOS，exit code 76 |
| Ctrl+R | 回標題 |
| Ctrl+C | 直接過關；第四關按則進片尾 |
| Ctrl+D | 重播音樂。`ASMDRV` 常駐時會讓遊戲凍結，是原版缺陷 |
| Ctrl+W | 把頁 0 四個平面寫到 `PIC.DA1`～`DA4` |

開發者秘技：Alt 歸零，依序按 `1`、`2`、`2`、`3`、`3`、`3`，再按數字鍵盤 `5` 啟用。之後空白鍵讓雙方血量回滿，數字鍵盤 `*` 讓受傷不減血。錯誤順序不啟用。
