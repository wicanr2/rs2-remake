## 顯示與輸入

- 工具列以下使用 512×288 的邏輯外框，中央遊戲安全區為 `(96,44,320,200)`，左右為 `(0,0,96,288)`、`(416,0,96,288)`。對應定案預覽 1920×1080 時，左右寬 360，中央為 `(360,165,1200,750)`。
- 視窗或螢幕比例不同時，整個外框等比置中；海報在外框兩側填滿，不改構圖、不鏡像。中央依目前顯示模式與戰場比例等比縮放，必要時留邊；海報模式允許非整數倍率以保持定案版面。原貌模式仍用最近鄰，HD 用線性濾鏡。
- 開啟海報時，桌面視窗按目前倍率改為 `512×288` 的倍數，再加工具列高度。關閉恢復既有 `320×200` 倍率。全螢幕與手機不強制改視窗大小；切換兩種海報時不改大小。
- 海報在遊戲畫面下層，震動夾在中央遊戲安全區。海報本身沒有命中區。工具列、設定與觸控按鈕沿用現有介面層與輸入接口，不把海報座標送進遊戲。
- 遊戲設定的「顯示」頁加入「海報」欄，按一下循環關閉、原始強化、現代手繪，略過不可用組別；左右鍵可前後切換。沒有任何可用組別時停用該欄。
- 在顯示頁保留大宇資訊、1990 年、說明書封面與美化重繪的來源說明。

## 設定與垂直鏈

`PosterMode` 為 `Off / Classic / Modern`。`settings.txt` 新增 `poster=off|classic|modern`，預設 `off`；舊設定檔缺欄位時用關閉，不影響其他欄位。無效值警告後用預設。退出與現有設定儲存流程一致。命令列 `--poster` 可覆寫初值供擷取與驗證。

垂直鏈為：手冊原圖 → 定案原稿／切片 → 固定雜湊 PNG 載入 → 前端兩側繪製 → 顯示設定切換 → 設定儲存／重開 → 正常標題及遊玩畫面。模擬、音訊、關卡與遊戲存檔無變動。

## 驗收與停止線

1. 資產重建驗四張固定切片與兩張定案預覽；執行時實檔驗證、缺單側及雜湊錯誤不得半組載入。
2. 單元測試驗設定相容性、循環／略過、UI 按鍵、版面比例、不重疊、邊界及新中文字完整。
3. SDL 無頭驗證同一段輸入在關閉與兩組海報之下的模擬雜湊相同；抽測 VGA、CGA、MGA 與寬戰場的等比置中。
4. Xvfb 正常標題入口實跑，截取兩組海報、顯示頁，確認兩側填滿、文字未裁切，從設定切換並重開確認保存。
5. 建置、外洩閘門及容器清理通過。以上只驗前端功能，不擴張為原版海報 parity 或 macOS／Android 實機驗收。

重跑入口：`tools/rust.sh play-build`、`tools/rust.sh play-test poster`、`tools/rust.sh play-poster-check`。GUI 驗證由 [poster_verify.py](../../tools/poster_verify.py) 執行，收據在本機 `workspace/rs2/poster-verification/`，同名批次已存在時拒絕覆寫。

刻意差異：原版沒有此功能，海報為美化重繪。沒有待猜補的原版行為。原稿與單張成品依既有規則只留本機，私人 repo 僅保存規格、工具、提示詞、雜湊與授權的定案／實跑對照圖；不建立新 Release，不覆寫已發布封包，不改可見度。
