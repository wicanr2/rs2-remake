# 006 顯示模式：VGA、EGA、CGA、MGA

狀態：CONFORMED（2026-11-05）。實作與驗收結果見最後一節。

使用者 2026-11-05 指定：CGA、MGA 要做，在重製內可以切換顯示模式，也要有 HD；原版四種模式都要留下來。依據是 [docs/re/14-display-modes.md](../re/14-display-modes.md)（132 處判斷點的盤點）、[規格 004](004-rewrite-and-delivery.md)「顯示模式」與 [規格 005](005-enhanced-mode.md)「工具列與設定畫面」。

## 範圍

| 項目 | 內容 |
|---|---|
| 模式 | `DisplayMode`：VGA、EGA、CGA、MGA（Hercules）。原版 `byte_1CF74`（M）的 `E`、`C`、`H` 加 `byte_1CF75`（P）的 `Y`、`N`：VGA 是 M=`E`、P=`N`，EGA 是 M=`E`、P=`Y` |
| 切換 | 工具列「顯示模式」按鈕與 F6（原版沒用 F6），循環 VGA、EGA、CGA、MGA。設定畫面「顯示」頁的分段按鈕直接選。設定檔 `mode=vga\|ega\|cga\|mga`（原子寫入，壞值退回 VGA），命令列 `--mode` 覆蓋，`--toggle-at N:mode` 供 headless 驗證在第 N 步後換模式。遊戲中隨時可切 |
| 不變 | 切換不改模擬：每步資料段雜湊相同。所有接收端永遠一起吃同一批繪製命令，切換只換顯示哪一個，所以切換當下的畫面一定正確 |
| 繪製 | VGA 沿用 `VgaSink`。EGA 與 VGA 用同一份平面，只換色表。CGA、MGA 用 `MonoSink`，逐位元組重現原版顯示記憶體 |
| 載入 | 單色圖庫 21 個檔，啟動時驗雜湊。缺檔或雜湊不符時 CGA、MGA 不可選，VGA、EGA 不受影響 |
| HD | VGA 沿用 `LayerSink`。EGA 的 HD 是 VGA HD 量化到 EGA 色表。CGA、MGA 的 HD 用 `MonoHdSink`（`workspace/hd/assets/mono/` 的 1,526 張推導結果，使用者之前決定單色不送生成模型），輸出 1280×800 |
| 喇叭附帶音 | 單色沒有。原版 `sub_18DCC`（特效 blit）在 E 才驅動 PC 喇叭。CGA、MGA 時不產生 `AudioMsg::Speaker`，AdLib 音樂不受影響 |

## 工具與地址空間

位址除標明 `dseg:` 者外，都是 IDA 線性位址，映像基底 `10000h`，`dseg:X` 是 `1CBC0h + X`。單色的偏移是 `A000h`、`B000h`、`B800h` 段內的 16 位元偏移，運算環繞，與 8086 的 `di`、`si` 相同。

- 反組譯：`tools/q.sh`（容器內）查 `workspace/ida/s_disasm.txt`。
- 動態：dosgolem `rs2dyn` 加 `tools/dosgolem-patches/0008-rs2dyn-mono-vram.patch`。

## typed behavior

### 命令與運算

核心記的繪製命令與模式無關（E 路徑的命令串）。`MonoSink` 對每個 `Op` 重現原版單色分支：

| 命令 | 單色底層 | 行為 |
|---|---|---|
| `S18C0A`、`S18FC1`、`S19068` | `19892h` | 覆寫字組，x 乘 2（位元組，16 像素） |
| `S18C6E` | `19840h` | 取反覆寫 |
| `S18CE2`、`S18DCC`、`S18EB6`、`S18F5D` | `1979Fh` | OR |
| `S18D89`、`S19025`、`S190CC` | `197EEh` | 取反 OR（受擊閃白、BEG 反相） |
| `S18D46`、`S18E30`、`S18E73`、`S18F1A` | `1974Bh` | AND（遮罩） |
| `S19ADC`、`S19B40` | `1A6CEh` | 圖庫項寫進暫存區（不裁切） |
| `S18ACE` | `19706h` | MAP 圖塊 10 列，每列 1 個字組 |
| `S19BA4`、`S19C4F`、`S19D08`、`S19DA8`、`S19F3B`、`S19E66`、`S19FF9`、`S1A09F`、`S1A144`、`S1A1E6` | `19C09h` 起 | 暫存區搬到顯示頁，各自的運算、列向、x 與來源指標公式見 `mono.rs` 函式註解 |
| `S1A287`、`S1929F` | `1A51Fh`、`198E1h`／`19925h` | 填色（`dx` 為 1 或 0Bh 時 0AAAAh）、血條（寫兩頁） |
| `S19CF9`、`S18894`、`S11504`、`S1152D`、`VramFill` | `1A332h`、`188CDh`／`188DEh`、`1151Ch`、`11545h`、`12932h` | 清目前頁、清兩頁、清暫存區、清頁 1 |
| `S1890D` | `18A61h` | 幀計數，BIOS 字型，寫 `di` 與 `di - 8000h` |
| `S1117F`（新） | `1117Fh` | 只有 H：目前頁 `0000h`～`1FFFh` 複製到 `2000h`～`3FFFh` |
| `S17FA0`、`S18031`、`S180C6` | `17FF5h`、`18086h`、`1812Eh` | 第三關：暫存區 A 的 40 欄 190 列送顯示頁（`S18031` 多 1 位元組），視窗歸零時暫存區 A 左移 50h 位元組。`S17EBA`、`S17EEA`、`S17F26`、`S17F5D` 是 E 的暫存區 B 維護，單色沒有 |

要點（都已由收據證實）：

- 單色 blit 以字組為單位：每列字組數是 `每列位元組數 >> 1`，字組位址超出列起點到列起點 + 4Fh、或列號超過 190（有號比較）就整個字組跳過，來源照樣前進 2 位元組。
- 暫存區搬移的迴圈條件 `cmp bx, 0BDh; ja` 是無號比較，負的列號直接結束；`cx` 不大於 0（有號）時只畫一列。
- `sub_1A1E6` 的單色分支不把 `word_26864` 乘 2，其他分支都乘 2，照原版。
- 第三關進場：E 在 `sub_17DF9` 末尾呼叫 `S17FA0` 後接 `S17EBA`，單色的 `sub_185AA` 沒有這一步顯示。`MonoSink` 在 `S17FA0` 前記下頁內容，緊接 `S17EBA` 時還原。
- `S1117F` 的原版呼叫端有 55 處（`sub_1117F` 的 call），`122C4h` 與 `1243Fh` 在 `retn` 之後，不可達。核心的呼叫位置依原版每個呼叫端對應，原始碼共 32 處（`title.rs` 23，其中 `two_page_loop!` 兩處展開成每個雙頁迴圈的兩個呼叫；`stage2～4.rs` 6；`flow.rs` 2；`ending.rs` 1）。正確性以 H 收據全過為證（動態已證實），沒有逐一對照每個位址的表。

### 第三關地形

`Game::set_terrain_scr(bool)`：第三關進場（`sub_13A51`）時讀取。單色模式設 `true` 讀 `SHT.SCR`，其他設 `false` 讀 `SHT.SCN`。進場之後再設不生效。`Session` 在建立與每次切換時依目前模式設定。

### 接收端與切換

- `Session` 持有 `VgaSink`、`LayerSink`、`MonoSink`（CGA）、`MonoSink`（MGA），`feed` 一次餵全部。
- 切換不碰 `Game`，只換 `render` 的輸出來源。
- 單色呈現：C 640×200、H 640×300（`B000h` 的三組掃描線：字元列 `s / 3`、列內第 `s % 3` 條，位址 = 列內序號 × 2000h + 字元列 × 80）。視窗大小不變，畫面在視窗內置中：CGA、MGA 以 4:3（原版在 4:3 螢幕上都是 4:3）填滿可用高度、線性縮放；VGA、EGA 維持 8:5（現狀，HD 美術是 1280×800）。單色 HD 是 1280×800，也以 4:3 呈現。
- 單色模式沒有補間與玩家機預測（固定原版時序）。幀計數在 CGA 只有第一頁有（`sub_1890D` 同時寫 `di` 與 `di - 8000h`，C 的 `8000h` 以上寫不進去），H 兩頁都有。
- EGA：補間關且原版圖時逐像素（屬性暫存器 `EgaAttr` 經 `ega_rgb16`）；補間開或 HD 時把輸出量化到目前 EGA 16 色。

### EGA 色表

核心的調色盤函式除了 `SetDac`，在 `start` 為 0 時另記 `DrawCmd::EgaAttr { regs }`：17 個屬性暫存器值。表在 DAC 表之前 11h 位元組，只有 `loader`（DAC 與 `title_d` 共用 `5A9h`，屬性表 `56Eh`）例外。6 位元 rgbRGB 轉 8 位元：位元 2、1、0 是紅、綠、藍（2/3 亮度），位元 5、4、3 是紅、綠、藍（1/3 亮度），每個通道 `2 × 主 + 副` 個 55h。開機時 `sub_1007D` 載入的 `00～07,38h～3Fh` 是標準 16 色，作為初值。

## 失敗模式

| 情況 | 處置 |
|---|---|
| 單色圖庫缺檔或雜湊不符 | `MonoAssets::load` 回傳錯誤，CGA、MGA 不可選並在狀態列說明，VGA、EGA 照常 |
| 圖號超出圖庫、來源超出圖庫位元組 | 計入 `MonoSink::anomalies`，該字組不畫，不 panic。收據涵蓋的範圍內為 0 |
| 設定檔的模式值不認得 | 退回 VGA |
| 暫存區或顯示記憶體偏移超出 | C 的 `8000h` 以上丟棄（原版是 ROM 區），暫存區超過 `0D000h` 丟棄 |

## 玩家路徑

- 標題、示範錄影、四關、四段過場與片尾在四種模式下都走得通，切換按鈕與 F6 在遊戲中任何時刻有效。
- CGA、MGA 沒有補間與玩家機預測（固定原版時序）；VGA、EGA 照舊。
- 沒有真人在實機驗證手感與畫面觀感，見「沒驗到的項目」。

## 原版 oracle

dosgolem `rs2dyn` 補 `0008-rs2dyn-mono-vram.patch`：`waittrace` 在 M 為 `C` 或 `H` 時每筆多記 `mm`、`mono`（顯示記憶體整塊的 SHA-256，C 是 `B8000..BFFFF` 32 KB，H 是 `B0000..BFFFF` 64 KB）、`hpage`（H 的 3B8h bit 7 選的顯示頁）、`msa`、`msb`（背景暫存區 A、B 各 `0D000h` 位元組的 SHA-256）；新命令 `dumpmono`（顯示記憶體與暫存區傾印、CRTC 暫存器）、`shotmono`（C 640×200，H 依 CRTC 解碼）。`internal/machine/hercules.go` 加兩個存取函式（`HerculesCRTC`、`HerculesModeReg`），不改既有行為。選模式用情境腳本在文字選單按鍵（`prefix-to-title-mono.txt`），不改 `S.EXE`。

收據目錄 `wm_<名稱>-<c|h>`，由 `tools/dos/wm_run.sh` 錄製，腳本 `tools/dos/scenarios/wt-<名稱>-<c|h>.txt`：

| 名稱 | 內容 | 筆數（每個模式） |
|---|---|---|
| `title` | 標題入口，開場動畫、示範錄影 1 與 2，回到標題 | 1,290 |
| `stage1`～`stage4` | 各關入口起，秘技（不減血），每幀開火，位置不動，打到關卡結束 | 1,192、1,066、1,406、1,851 |
| `flow` | 標題進遊戲，四關各玩幾秒，Ctrl+C 過關，四段 J 過場，片尾，Q 離開 | 437 |
| `menu` | 標題選單的 LEVEL、CTRL 走一輪，涵蓋選單反白（`S18C6E`） | 200 |

### 與 E 的資料段差異（不進模擬）

`mono_exempt` 豁免三處，都不是模擬欄位：`word_2685A`（`9C9Ah`，`sub_1A70A` 的結果）、檔名字串表（`A92Ah`～`AAE1h`，`sub_1C738` 就地換副檔名字元）、第二關 `stage2_d` 淡出工作表（`0C96h`～`0CD6h`：E 在幀 > 0A0h 每幀由 `sub_13894` 調暗，C、H 的 `sub_13894` 在第一個比較就 `retn`）。C 的 `word_26872` 在 `DS_EXEMPT` 內。

### 沒驗到的項目

- 實機（CGA、Hercules、EGA 顯示卡與螢幕）。EGA 的 oracle 只有屬性暫存器的值（核心 `EgaAttr` 對 dosgolem 收據相同）；色表是 EGA 硬體的定義，dosgolem 在 VGA 的 EGA 模式的 DAC 預設值不是 rgbRGB 色表，不能當色表的 oracle。
- EGA 在補間或 HD 時的量化沒有原版對照。
- 單色 HD 沒有原版 oracle。推導圖與 SD 圖的相關係數中位數：`MY` 0.47、`SHT1～5` 0.49～0.68、`BH1`、`BH2`、`BH4` 0.28～0.43、`BEG1` 0.35，`MAP.BDB` 只有 0.046（第三關地形圖塊的細節與 SD 不像）。操作語意以「HD 圖換成 SD 最近鄰放大」的嚴格比對驗證（14,884 筆相同），圖本身的品質由使用者決定要不要重畫。
- 手感與畫面觀感沒有真人驗證。
- Android 資料包要含 21 個單色圖庫檔，否則 CGA、MGA 在那邊不可選。
- 狀態列的 `ST_MONO_MISSING` 字樣受內附點陣字型的字集限制，要更清楚的措辭需重烘 `ui-font.bin`。
