# 005 強化模式與設定介面

狀態：DRAFT（2026-11-05）

使用者 2026-11-05 定位：這是台灣自製的 R-Type 類射擊遊戲，有文化保存的必要。所以原版規則永遠保留，強化全部是選項，可以從工具列設定。

本規格的內容不是從原版導出的，全部屬於 remake-owned。行為的依據是這份規格與單元測試，沒有原版收據可以對拍。

## 原則

| 項目 | 規則 |
|---|---|
| 原版模式 | 所有會改變規則的選項關閉時，全部收據逐位元組相同。`tools/rust.sh verify` 永遠用這個狀態跑 |
| 決定性 | 強化開啟時，同樣的輸入與選項仍得到同樣的結果 |
| 預設值 | 改變規則的選項預設關閉。AI 強化使用者明確要求預設關閉。只影響顯示與聲音的選項預設開啟 |
| 依賴 | 改變規則的選項等對應領域重寫完才做（規格 004），不在平坦資料段上寫 |
| 標示 | 有任何改變規則的選項開著時，狀態列顯示「強化規則」。截圖與錄影看得出來不是原版 |
| 原版美術 | 製作者署名與商標不動。新特效用既有素材或程式產生，要新美術時另走 HD 流程 |

| 射擊 | 打擊回饋 | 開、關 | 開 | 否 |
| 練習 | 無敵 | 開、關 | 關 | 是 |
| 操控 | 手感（玩家機預測、短按保留） | 新、原版時序 | 新 | 否 |
| 操控 | 細步移動 | 開、關 | 關 | 是 |

改變規則的選項在遊戲中切換時，戰場大小等下一次進關才生效，其他立刻生效。

## 戰場大小

原版四關的生成表共 342 列，154 列在畫面右緣 x=320（欄 40）生成，只有 9 列在欄 40 右邊，其餘在畫面內或上下方（靜態已證實，讀 `dseg:41BEh`、`54FEh`、`68E0h`、`7922h` 各列樣板的 w9、w10）。玩家子彈也在原版邊界附近消失，碰撞格網只有 40 欄。所以只拉遠鏡頭看不到更多敵人，要真的加大戰場。

| 項目 | 100%（原版） | 120% | 150% |
|---|---|---|---|
| 可視範圍（邏輯像素） | 320×190 | 384×228 | 480×285 |
| 玩家活動範圍 | 欄 1 至 33，列 0 至 16 | 按比例 | 按比例 |
| 敵人進場 | 欄 40 | 依新右緣平移 | 依新右緣平移 |
| 子彈與碰撞格網 | 40 欄 | 48 欄 | 60 欄 |
| 血條與文字 | 原位 | 固定在畫面底部，不縮小 | 同左 |

- 敵人的時間表不改。進場距離變遠，所以到達玩家面前的時間會晚。接受這個差異，不改表。
- 上下方生成的敵人依比例平移。腳本內的相對位移不改。
- 頭目的位置靠右對齊新右緣。
- 背景本來就循環捲動（第一關 40 位元組週期），可以往右延伸。第三關地圖 4800 像素寬。地圖視窗跟著放大。
- HD 素材不必重畫。原版圖模式輸出 384×240、480×300，HD 模式輸出同比例的 4 倍。

## 射擊

原版一次按放只射一發，按住不連射。大掃射要裝滿兩座砲座，按住 14 個鍵盤事件以上，也就是靠鍵盤自動重複計數（`docs/re/11-entities-combat.md` 6.1）。手把沒有自動重複，這是原版操控不佳的主因之一。

| 選項 | 行為 |
|---|---|
| 波動砲充能 | 按住開火鍵累積充能，以邏輯步計數，不看鍵盤事件。不需要砲座。畫面底部顯示充能條。放開時依充能量射出三級波動砲：第一級沿用普通彈加大，第二級穿透，第三級沿用大掃射的穿透彈加上全高度判定 |
| 按住連射 | 按住開火鍵時每 2 個邏輯步射一發普通彈。和波動砲同時開著時，連射照常，放開才結算充能 |
| 砲座像 Force | 原版的轉向鍵維持前後轉向。新增「分離」鍵：砲座脫離機身往前飛，碰到敵人造成傷害並擋子彈，再按一次收回。可從前方或後方接回，接回的方向決定朝向 |
| 打擊回饋 | 命中閃白、大爆炸時畫面短暫震動、射擊與爆炸音效加重。只在顯示與音訊層，由模擬回報事件，不改判定 |

## 無敵

使用者要求的選項。使用原版已有的作弊判斷（`word_273A5`：`Y` 時不減血），開啟時狀態列顯示「無敵」。

## 操控

原版操控不佳的原因與對應：

| 原因 | 對應 |
|---|---|
| 邏輯一秒 9.1 步，按鍵到畫面最多 220 毫秒 | 玩家機預測（規格 004「體感」） |
| 兩步之間的短按會漏 | 短按保留（規格 004「體感」） |
| 一步走 16 像素，難以微調 | 細步移動：水平 8 像素、垂直 5 像素一步，邏輯步內走兩次判定，總速度相同 |
| 充能靠鍵盤自動重複 | 波動砲充能以邏輯步計數 |
| 只能用鍵盤 | 手把，見下節 |
| 鍵位固定，右 Shift 開火對部分鍵盤不便 | 鍵盤可重綁，見下節 |

## 工具列與設定畫面

依使用者指定，參考 `~/cht/快打至尊/superfighter-remastered` 的做法（`internal/desktop/game.go`、`docs/spec/005-native-desktop.md`，那邊的 `docs/screenshots/gamepad-settings.png`、`keyboard-settings.png` 是版面範例）。工具列在遊戲畫面之外，不蓋遊戲。

工具列是中文按鈕：

| 按鈕 | 作用 |
|---|---|
| 開始／繼續 | 繼續遊戲 |
| 暫停 | 暫停 |
| 控制設定 | 開設定畫面的手把或鍵盤頁 |
| 遊戲設定 | 開設定畫面的強化頁 |
| 全螢幕 | 全螢幕 |
| 原貌／HD | 原版圖與 HD |
| 顯示模式 | VGA、EGA、CGA、MGA（規格 004） |

工具列下方一行狀態列：暫停、強化規則、無敵、手把接上或拔除等訊息。

設定畫面蓋在遊戲畫面上，開著時遊戲暫停。F10 開關，F8 換頁，Tab 選欄位，Esc 關閉。

| 頁 | 內容 |
|---|---|
| 手把 | 第 1 人、第 2 人各指派一支手把。不能重複指派，非標準配置明示不支援。拔除時取消該玩家的指派，重接要再指派。沒有手把時顯示「尚未偵測到手把。USB／藍牙配對請由作業系統完成。」 |
| 手把按鍵 | 開火、轉向、分離、暫停、確定的按鈕可以改。方向固定十字鍵與左搖桿 |
| 鍵盤 | 兩人各自的上、下、左、右、四個斜向、開火、轉向、分離。點欄位或按 Enter 後按新鍵，Delete 清空，Esc 取消，衝突時不覆寫。有「兩人鍵盤還原預設」 |
| 遊戲 | 本規格「選項」一節的全部選項，每行一個，分群組 |
| 顯示 | 補間、幀計數、倍率、工具列 |

規則：

- 鍵盤與手把的按鍵來源分開計數，最後一個來源放開才送放開碼。
- 開設定畫面或視窗失焦時放開全部來源，恢復前要求先放開按鍵，不把設定畫面的按鍵送進遊戲。
- 手把的 Start 暫停遊戲。
- 設定存使用者設定目錄，寫入是原子的。手把指派不存，裝置編號重啟會變。
- 中文字型用 Noto Sans CJK TC（OFL），只把介面用到的字烘成點陣放進程式，發行包帶 OFL 全文。
- Android 用同一個設定畫面，字放大，手指點選。

## 驗收

| 編號 | 項目 | 通過條件 |
|---|---|---|
| E1 | 原版模式 | 全部選項為預設時，`tools/rust.sh verify` 全過。改變規則的選項全關時每步雜湊和原版收據相同 |
| E2 | 決定性 | 每個選項開啟時，同一份輸入跑兩次雜湊相同 |
| E3 | 開關有效 | 每個選項有單元測試，證明開啟後行為確實改變，關閉後回到原狀 |
| E4 | 戰場大小 | 120%、150% 從第一關玩到片尾不當掉，敵人從新右緣進場，玩家到得了新邊界 |
| E5 | 設定畫面 | 重綁、衝突、還原預設、指派、拔除都有單元測試。不把設定畫面的按鍵送進遊戲 |
| E6 | 字型 | 介面上的每個字都有點陣，有測試掃過全部字串 |

手感、打擊回饋的強度與 AI 的難度沒有真人驗證時要寫明。
