# 001 Rust 重製第一關垂直切片

狀態：DRAFT

## 範圍

第一關可玩：載入素材、背景捲動、實體生成與移動、玩家移動與開火、碰撞、血量、道具、頭目、過關判定。用 `DM1.LCK` 重播與原版逐幀對拍。

不含：開場、選單、過場、第二到第四關、音樂、音效、單色模式、破解層。第一關頭目的擊殺收據還沒有，見「READY 前要補」。

## 輸入

| 檔案 | 用途 |
|---|---|
| `MY.GO`、`SHT1.GO`、`BH1.GO` | 圖庫 |
| `S.EXE` | 解包後取實體樣板、移動腳本、時間表、調色盤、亂數表 |
| `DM1.LCK` | 重播測試 |

雜湊以 [source-manifest.json](../../source-manifest.json) 為準。任何一個不符就拒絕啟動，錯誤訊息要寫出檔名與預期雜湊。

## 素材來源

啟動時從玩家自備的原版即時解碼，repo 與發行包不收原版位元組。`S.EXE` 的 LZEXE 解包要在 Rust 內重做，規則同 `tools/unpack_exe.py`。

HD 素材是獨立的本機資料夾，以 `--hd <路徑>` 指定，沒給就顯示原版圖。沒有原版就不能玩，這一版沒有替代美術。

## 架構

Rust 1.99.1，edition 2024，Docker 映像 `rust:1.99.1-slim-bookworm`。

| crate | 職責 | 相依 |
|---|---|---|
| `rs2-formats` | LZEXE、RLE、圖庫、`.GO` 區段、調色盤、時間表、樣板、腳本解析 | 無 |
| `rs2-core` | 決定性模擬：`step(&mut State, Input) -> Frame`。不碰時間、檔案、亂數源或繪圖 | `rs2-formats` |
| `rs2-play` | 視窗、輸入、計時、繪製 | `rs2-core`、`sdl2 =0.38.0` |
| `rs2-trace` | 無視窗跑重播，輸出逐幀狀態 TSV | `rs2-core` |

`rs2-core` 不用浮點數，整數寬度與溢位比照原版 16 位元，要環繞的地方明確寫 `wrapping_*`。

## 驗收

| 編號 | 項目 | 通過條件 |
|---|---|---|
| A1 | 格式跨實作 | Rust 解出的每個圖庫項目與 `tools/extract_assets.py` 的 RGB 內容雜湊相同。工具匯出與 Rust 各自計算 |
| A2 | 重播對拍 | `DM1.LCK` 重播 640 幀，每幀比對玩家位置、血量、武器、砲座、15 個實體槽的存活、位置與影格、子彈池。與 dosgolem 逐幀收據完全相同 |
| A3 | 雜湊拒絕 | 改任一輸入一個位元組，程式拒絕啟動，並有負對照測試 |
| A4 | 正常玩家路徑 | 鍵盤從第一關開始，打到頭目並過關，原版與重製用同一組固定輸入比較結果 |
| A5 | 畫面 | 固定幀截圖與 dosgolem 同狀態畫面比對：原版圖模式逐像素相同，HD 模式由人判讀 |

單元測試與 A1 通過不算完成。A2、A4 都通過才能標 CONFORMED。

## 已知差異

### 刻意不照做

| 原版 | 重製 | 為什麼 |
|---|---|---|
| 密碼畫面查手冊顏色 | 不做 | 防拷，不是遊戲內容 |
| Ctrl+D 在 `ASMDRV` 常駐時讓遊戲凍結 | 不重現 | 驅動串接的缺陷 |
| 開場飛船是連雲層貼上的矩形 | HD 模式只畫物件、四周透明 | 見 [HD 文件](../hd/codex-handoff.md)。開場不在本切片，先記著 |

### remake-owned

| 項目 | 到期條件 |
|---|---|
| 視窗大小與縮放 | 永久，原版沒有對應概念 |
| 暫停與設定介面 | 永久，原版沒有對應概念 |

## 失敗模式

- 缺檔或雜湊不符：拒絕啟動。
- HD 資料夾缺某張圖：該張退回原版圖並在畫面標記，啟動日誌列出缺的項目。
- 重播與原版不同：`rs2-trace` 回報第一個不同的幀與欄位。

## 權利邊界

重製程式碼採 RRSAL-1.0。原版素材與 HD 圖不進 repo 與發行包。對外展示另外問使用者。
